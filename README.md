# nora-portfolio

Portfolio of Minh (Nora) Nguyen, product designer. Live at https://nora-des-portfolio.vercel.app. Plain static HTML, CSS and JS, deployed on Vercel.

- `/` the exhibition: a sideways-scrolling home page (stacks vertically on phones)
- `/coco/`, `/dynatax/`, `/zalo/`, `/pocketplus/` case studies with a section navigator
- `/blog/` blog posts (still on the previous site's styles)
- `/resume.pdf` resume

Design source: the Claude Design canvas "Nora Nguyễn — Portfolio Hero".
Zalo and Pocketplus+ case images are hotlinked from their figweb sites, the same as on the previous portfolio.

Preview locally with any static server, for example `python3 -m http.server`, then open http://localhost:8000.
